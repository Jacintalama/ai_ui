# Lumen — Launch Site

A one-page launch site for a fictional product ("Lumen") with an embedded animated **launch promo** that plays inside the browser (four scenes, autoplay, replay/pause). Also includes features, how-it-works, pricing, FAQ, and a localStorage-backed waitlist form.

## Run

Serve the folder statically:

```
python -m http.server 8000
```

Then open `http://localhost:8000/`.
