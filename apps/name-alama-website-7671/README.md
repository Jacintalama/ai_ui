# Alama Forms (name-alama-website-7671)

A stateless, no-build drag-and-drop form builder. Three views in the top tab bar: **Builder** (drag fields from a palette, click to edit label/placeholder/options/required, drag to reorder), **Preview** (renders the form as respondents would see it, with a shareable URL), and **Responses** (table of submissions with CSV export). Eight field types are supported: short text, long text, single choice, multiple choice, number, date, email, URL. Schema lives in memory as JSON; responses are session-only with no persistence.

## Run

Open `index.html` directly in a browser, or serve the folder with any static file server (e.g. `python3 -m http.server`). No build step, no install.
