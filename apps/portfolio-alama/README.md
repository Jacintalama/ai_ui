# Portfolio - Alex Alama

A professional portfolio website showcasing 5 years of software engineering experience. Built with static HTML, Tailwind CSS, and Alpine.js for a fast, responsive, and accessible user experience.

## Features

- Responsive design (mobile-first, 320px+)
- Semantic HTML5 structure
- Accessible with WCAG 2.1 AA compliance
- Interactive mobile navigation
- Skills grid with 12 technologies
- 4 featured projects with detailed descriptions
- Contact section with social links

## How to Run

Simply open `index.html` in a web browser. No build step or npm install required.

For local development with live reload, use any static file server:

```bash
# Python
python -m http.server 8000

# Node.js (using npx)
npx serve .

# VS Code Live Server extension
```

Then navigate to `http://localhost:8000` (or the port shown).

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Alpine.js 3.x
- Lucide Icons
- Vanilla JavaScript (ES modules)
