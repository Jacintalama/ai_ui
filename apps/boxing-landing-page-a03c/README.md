# Champion Boxing Academy

A modern, responsive landing page for a boxing gym featuring training programs, trainer profiles, and a contact form.

## What it does

- Displays a hero section with compelling call-to-action buttons
- Showcases gym information with statistics and background details
- Lists three training programs (Beginner, Advanced, Personal Training) with features and pricing
- Features four trainer profiles with credentials and specializations
- Provides a contact form for visitor inquiries with validation
- Includes gym location, hours, phone, and social media links
- Fully responsive navigation with mobile menu
- Smooth scrolling between sections

## How to run

1. Open `index.html` in a web browser
2. No build process or dependencies required - all assets load from CDN
3. The page works entirely in the browser with no backend needed
