# Crumb and Co

A landing page for Crumb and Co, a small artisan bakery in Basel that specializes in sourdough bread and pastries. The page helps people discover the bakery and encourages them to visit the physical location.

## What it does

- Introduces the bakery and its focus on handmade sourdough and pastries
- Showcases the main product categories: sourdough breads, fine pastries, and seasonal offerings
- Explains the sourdough process through four clear steps
- Provides location, opening hours, and contact information for visitors
- Clean, confident design inspired by Swiss design principles and artisan craft values

## How to run

Open `index.html` in a web browser. No build process, server, or dependencies required.

The page is a static HTML site using:
- Tailwind CSS (loaded via CDN)
- Alpine.js for minimal interactivity (icons initialization)
- Lucide icons for UI elements

All assets are self-contained in the project directory.
