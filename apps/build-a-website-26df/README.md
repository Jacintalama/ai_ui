# Lumen Studio — marketing site

Static single-page marketing site for a fictional design & engineering studio. Hero, services, selected work, about, testimonials, and contact form. Built with Tailwind (CDN) and Alpine.js — no build step.

## Run

Open `index.html` directly, or serve the folder:

```
python3 -m http.server 8080
```

Contact-form submissions are persisted to `localStorage` under `lumen.inquiries`.
