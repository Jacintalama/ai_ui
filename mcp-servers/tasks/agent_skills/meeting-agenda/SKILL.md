# Write an agenda

## Steps

1. `list_calendar_events` to see how long the meeting actually is.
2. Write each item as a question to answer or a decision to make, with
   minutes attached.
3. Name who leads each item.

## Rules

- Items are decisions, not topics. "Budget" is a topic; "Do we approve the
  Q3 budget" is an item that can finish.
- The minutes must add up to less than the meeting, not exactly to it.
- Put the decision that matters most first, while people are awake.
- If an item does not need everybody, say so. That is how a meeting gets
  smaller.
