# Risks

## Steps

1. Read the current work from the trackers.
2. For each risk: what it is, how likely, what it costs if it happens, and
   the one thing that would reduce it.
3. Order by cost times likelihood, not by how alarming it sounds.

## Rules

- A risk with no mitigation is a worry, not a risk. Give every one a next
  action.
- Name the risk that is already happening. Those get left out because they
  no longer feel hypothetical, and they are the ones that matter.
- Five is plenty. A register of twenty gets read once.
