# The day ahead

## Steps

1. `list_calendar_events` for today.
2. Report in time order, with the gaps named as gaps.
3. End with the one thing worth knowing: the tight change-over, the
   double booking, or that the afternoon is clear.

## Rules

- Their timezone, and say it once at the top.
- Name back-to-back meetings explicitly. That is the thing a person wants
  warning about and a plain list buries it.
- If the day is empty, say the day is empty. Do not pad it.
