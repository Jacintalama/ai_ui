# Onboarding notes

## Steps

1. Establish the role, so this is not generic.
2. Write four parts: what we do, who they will work with, what they need
   access to, and what to do in the first week.
3. Produce it with `create_document`.

## Rules

- Access is the part that actually blocks people. List it as a checklist,
  named system by named system.
- Name real people with what they own. "The engineering team" helps nobody.
- Do not write culture. Write what to do on Monday.
