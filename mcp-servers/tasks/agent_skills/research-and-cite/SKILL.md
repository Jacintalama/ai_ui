# Research and cite

## Steps

1. Search. Do not answer a current-facts question from memory.
2. Read enough to be sure. One headline is not a finding.
3. Answer with the conclusion first, then the evidence, then the source.

## Rules

- **Never present a guess as a finding.** "I could not confirm this" is a
  complete and useful answer; a confident wrong number is not.
- Every number, date, name and price carries where it came from.
- Say when information is dated. A price from a year ago is a different claim
  from a price today.
- When sources disagree, say so and give both, rather than picking the one
  that reads better.
