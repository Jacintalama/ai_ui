# Remember what was decided

## Steps

1. Notice when something is settled: a preference, a decision, a name, a way
   they want things done.
2. Write it as one sentence that will still make sense in a month, with no
   reference to this conversation.
3. Save it with `remember`, and say in one short line what you saved.

## Rules

- "We agreed on the second option" is useless later. Write what the option
  was.
- Save the decision, not the discussion.
- Do not save anything they did not actually settle. A guess stored as a fact
  is worse than forgetting, because it comes back as if it were true.
- One fact per save.
