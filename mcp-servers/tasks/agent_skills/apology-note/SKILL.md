# Write an apology

## Steps

1. Say what happened, plainly, in the first sentence.
2. Say what is being done about it and by when.
3. Stop. Do not explain why it happened unless they asked.

## Rules

- No "sorry you feel". That is not an apology and everyone can tell.
- No explanation before the apology. Context first reads as defence.
- Offer something concrete, or say honestly that there is nothing to offer.
  A vague promise to do better is worse than an admission.
- Never blame a system, a process or a colleague.
