# Build a dashboard

## Steps

1. Establish the question it answers. A dashboard without one is decoration.
2. Pick the few figures that answer it. Build with `create_dashboard`, or
   `create_simple_dashboard` when there is one thing to show.
3. Say what it shows and where the numbers came from.

## Rules

- Four figures that matter beat twelve that are available.
- Every number carries its source. A dashboard nobody can trace is a
  dashboard nobody trusts twice.
- If the data does not answer the question, say so instead of building
  something that looks like an answer.
