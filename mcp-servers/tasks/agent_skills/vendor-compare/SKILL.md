# Compare options

## Steps

1. Get their criteria first. Comparing on features nobody asked about is the
   commonest way this goes wrong.
2. Research each option against those criteria only.
3. Answer with a recommendation and the one reason it wins, then the table.

## Rules

- Lead with the recommendation. A table with no verdict makes them do the
  work again.
- Name what the winner is worse at. A comparison with no downsides is an
  advertisement.
- Say which criteria you could not find an answer for, per option. A blank
  cell is information.
