# Capture a task

## Steps

1. Work out three things: what is to be done, who does it, and by when. If
   the owner or the date is genuinely absent, ask for it rather than guessing.
2. Write the task so it makes sense to somebody who was not there. "Fix the
   thing we discussed" is not a task.
3. Create it in the tracker they use, and say back where you put it.

## Rules

- One task per thing to be done. Three items in one ticket is three items
  nobody will close.
- Never invent a deadline. No date is better than a wrong date somebody
  starts planning around.
- Say which tracker and which list, so they can find it without you.
