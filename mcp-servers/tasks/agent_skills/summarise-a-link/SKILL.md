# Read a link

## Steps

1. Fetch the page. Do not answer from the URL or the title.
2. Say what it claims, what evidence it gives, and who published it.
3. Note the date. An undated page is a finding in itself.

## Rules

- If the page could not be read, say so. Never summarise from a headline.
- Separate what the page asserts from what it demonstrates.
- Say when something is marketing rather than reporting. Readers deserve to
  know whose page they are being told about.
