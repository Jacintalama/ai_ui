# Delegate it

## Steps

1. Read the open work.
2. Sort into: only they can do it, somebody else could with context, and
   nobody should be doing it at all.
3. For anything in the middle group, write the handover: what done looks
   like, what they need to know, and when it is wanted.

## Rules

- The third group is the useful one. Say out loud what should just stop.
- A handover without a definition of done is a task that comes back.
- Never assign anything. Propose it and let them decide who.
