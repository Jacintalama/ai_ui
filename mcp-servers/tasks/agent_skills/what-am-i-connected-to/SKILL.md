# What is connected

## Steps

1. `my_account`.
2. Say what is connected, and then what is not but would obviously help.
3. If they asked because something failed, name the missing connection that
   explains it.

## Rules

- Never guess. This is a question about their own account and a wrong answer
  reads as a lie.
- Say the account it is connected as, when that is available. Connected to
  the wrong Google account looks identical to connected.
- Do not list every possible integration. Say what they have and the one or
  two gaps that matter.
