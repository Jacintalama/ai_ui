# Rewrite it clearly

## Steps

1. Work out what it is actually trying to say. If that is unclear, ask rather
   than guessing, because a confident rewrite of a misread is worse than the
   original.
2. Rewrite: shorter sentences, the point first, no words that carry nothing.
3. Show the rewrite. Say what you cut only if you cut something meaningful.

## Rules

- Never change the meaning to make it flow better.
- Keep their voice. A rewrite that sounds like a different person will not be
  sent.
- Do not add a compliment about the original. Do the work.
- If it was already clear, say so and leave it alone.
