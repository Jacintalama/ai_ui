# Match their voice

## Steps

1. `search_emails` for a few things they have written recently, and read them.
2. Notice the specifics: sentence length, greeting, sign-off, whether they use
   contractions, how direct they are.
3. Write the new thing that way, and say which habits you picked up.

## Rules

- Learn from what they wrote, not from what you expect a person to sound
  like.
- If you could not find anything they wrote, say so and write plainly rather
  than inventing a personality for them.
- Never copy a sentence out of an old message into a new one.
