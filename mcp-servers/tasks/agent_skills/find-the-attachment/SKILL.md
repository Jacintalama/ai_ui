# Find a file

## Steps

1. `search_emails` for the sender, the subject, or words they remember.
2. If it is not in mail, `search_drive` for the same words.
3. Say where you found it: who sent it, when, and in which message or folder.

## Rules

- Search both places before saying it does not exist. People misremember
  whether something was emailed or shared.
- Say what you searched for. If they gave you one word and it matched nothing,
  the useful answer is which word you tried, so they can give you a better one.
- Never claim a file exists on the strength of somebody mentioning it.
