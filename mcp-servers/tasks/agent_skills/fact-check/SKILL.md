# Fact check

## Steps

1. Pull out every checkable claim: figures, dates, names, quotations,
   superlatives.
2. Check each one. Search rather than recalling.
3. Report per claim: **confirmed**, **wrong** with the right answer, or
   **unverified** with what you tried.

## Rules

- "Unverified" is a real verdict and the most useful one to be honest about.
  Marking something confirmed because it sounds right is the failure mode.
- A superlative is a claim. "The fastest", "the only", "the first" all need
  checking and almost never survive it.
- Do not rewrite the text. Report, and let them decide what to change.
