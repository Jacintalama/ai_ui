# Groom the backlog

## Steps

1. Read the open items and find those untouched for more than thirty days.
2. Sort each into: **close it** (overtaken or done elsewhere), **rewrite it**
   (nobody could act on it as written), **keep it** (still real, just not now).
3. Present the list with your reason for each, and change nothing yet.

## Rules

- Propose, never close. A backlog item somebody cared about is not yours to
  delete, and this is exactly the job where being wrong is invisible.
- Give a reason per item. "Stale" is not a reason, it is the criterion.
- If nothing is stale, say the backlog is healthy and stop.
