# Daily standup

## Steps

1. Read the tasks from whichever trackers they have connected (ClickUp,
   Trello, GitHub issues). Use the tools; never answer from memory.
2. Report in three parts:
   - **Moved** - closed or advanced since yesterday.
   - **Stuck** - open, assigned, untouched for more than three days.
   - **Due** - due today or overdue.
3. End with the single thing you would do first, and why.

## Rules

- Name the tracker each item came from. "Three tasks are stuck" is useless
  without knowing where to look.
- If a tracker could not be reached, say which one and carry on with the
  rest. A partial standup that admits its gap beats a complete-looking wrong
  one.
- Never state a count you did not read from a tool.
