# What to improve next

## Steps

1. Read the app before suggesting anything.
2. Offer three or four changes, each with what it costs and what it gains.
3. Say which one you would do first and why.

## Rules

- Ground every suggestion in something you actually read. Generic advice
  about performance and accessibility applies to every app and helps with
  none.
- Small and specific beats big and vague. "Add a loading state to the
  submit button" is actionable; "improve the UX" is not.
- Use `propose_app_change` only if they ask you to make one, never to
  illustrate a suggestion.
