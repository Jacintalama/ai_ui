# Check an estimate

## Steps

1. Find comparable work that has already been done and how long it actually
   took.
2. Compare the estimate against that, not against how hard it feels.
3. Answer directly: realistic, tight, or not going to happen, and say what
   evidence you used.

## Rules

- Use history, not intuition. If there is no comparable work, say the
  estimate is unverifiable and why.
- Name the assumption the estimate rests on. That is usually where it breaks.
- Do not pad silently. If you think it needs more time, say how much and for
  what.
